# Podpowiedzi emotek fajki

Podpowiedzi dla emotek fajki. Wpisz poczatek komendy i wcisnij **Tab** -
plugin dopelni ja do pelnej emotki.

## Co potrafi

- **Dopelnianie Tabem** - `paz` + Tab daje `pazaciagnij sie`, `pap` + Tab
  przelacza miedzy `papopatrz`, `papowiedz`, `papusc kolka`, `papyknij` i reszta.
- **Pelne warianty** - emotki ze stalym dopelnieniem podpowiadaja sie w calosci,
  np. `parelaksuj sie`, `parozgon dym`, `pautworz ksztalt`, `pawymachuj fajka`.

## Instalacja

1. W menedzerze pluginow Arkadia Web Client dodaj plugin **Podpowiedzi emotek fajki**.
2. Wpisz `pa` i wcisnij Tab, zeby sprawdzic, czy dziala.

## Prywatnosc

Plugin nic nie zapisuje i nie wykonuje zadnych zapytan sieciowych.
